One line under 200 characters that gets you out of work and gets a laugh: a sick-day excuse a boss might half believe, with the twist landing at the very end.

> Can't make it in today — I slept on my neck wrong and now I can only turn left, so my commute just became a 400-mile round trip.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (128 characters, one line, no trailing newline). Pure Python standard library, deterministic: the same line on every run.
